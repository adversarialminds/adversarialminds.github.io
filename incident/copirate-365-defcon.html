Kill-chain analysis

Initial AccessIndirect (I)
The injection sits in a malicious Word document shared with the victim, who only chats with Copilot.
The attack scenario in this demo is the user interacting with a malicious Word document that was shared with them. embracethered.com/blog/posts/2026/defcon-talk-copirate-365/ (Walkthrough Copirate in Microsoft Word Stealing Emails)
Priv. Esc.Instruction override (IO)
The document's instructions take over Copilot's inference and direct its tool calls.
The indirect prompt injection hijacks inference and misaligns Copilot (aka now Copirate) to search for the email with “the code” embracethered.com/blog/posts/2026/defcon-talk-copirate-365/ (Walkthrough Copirate in Microsoft Word Stealing Emails)
Recon.Yes
The post enumerates Copilot's tools (including record_memory) before building the exploit.
I did a quick bypass by asking Copilot to create an xml document and print the names of the tools as XML elements into the document. embracethered.com/blog/posts/2026/defcon-talk-copirate-365/ (Extracting System Prompt Information and Tools)
Persist.Independent (memory)
The payload makes Copilot call record_memory, so the exfil instruction fires in every future conversation.
This persisted new memories to M365 Copilot that compromised all future conversations. embracethered.com/blog/posts/2026/defcon-talk-copirate-365/ (Adding Memories via Prompt Injection)

Lat. Mov.—not demonstrated
